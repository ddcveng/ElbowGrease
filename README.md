# Elbow Grease
This repository contains a little 3D game that I made in a week for a game jam. 
It is written in the odin programming language using raylib with openGL for the graphics. 

You can build it simply by running `odin build .` in the root of the repository. All that is required is the odin compiler.
Alternatively, you can just grab the binary from the [itch.io](https://ddcveng.itch.io/elbow-grease) page.
